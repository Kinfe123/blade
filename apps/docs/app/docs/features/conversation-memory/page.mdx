# Conversation Memory

Conversation memory keeps recent messages so follow-up questions have context.
## What You Can Do

## How It Works
1. Store user and assistant messages under the current user and channel.
2. Include recent history when asking the AI provider for a follow-up answer.
3. Drop old messages after the configured timeout or when a user clears history.
## Behavior Details
- Old conversations expire or are cleaned up so stale context does not leak into later answers.
