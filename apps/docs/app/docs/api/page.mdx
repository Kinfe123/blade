# API Reference

The API reference collects the concrete developer surface of Blade: terminal commands, import paths, route handlers, adapters, configuration helpers, and type contracts. Start with the page that matches what you are trying to call or run, then move to setup and configuration pages when you need the surrounding runtime context.

## Pages In This Section
- [CLI](/docs/api/cli) - Commands and flags for running repository workflows from the terminal.
- [Configuration API](/docs/api/config) - Configuration types, helpers, and contracts used by application developers.
