# About These Docs

The Blade documentation covers everything you need to build, configure, and deploy a Blade application. It is organized into a few areas.

**Get Started** walks you through creating a new project, the installation steps, and a quickstart that produces a running app. If you're new to Blade, start there.

**Pages** covers the core runtime concepts: how pages and layouts work, the data model and hooks, components, API routes, and the TypeScript client for querying RONIN directly.

**Deployment** explains how to take your compiled app to production on Vercel, Cloudflare, Netlify, or any container environment.

If you run into questions not covered here, the [RONIN documentation](https://ronin.co/docs) covers the database layer that Blade integrates with most tightly.
