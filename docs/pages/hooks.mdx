# Hooks

Blade's API surface is built around React hooks. Server hooks run only on the server (inside server components and layouts); client hooks run only in client components (files ending in `.client.tsx`).

## `use` (Server)

Reads data from your database. All `use` calls across layouts and the current page are collected and executed as a single database transaction before rendering begins.

```tsx
import { use } from 'blade/server/hooks';

const Page = () => {
  const accounts = use.accounts();

  return <>{accounts.map(a => <span key={a.id}>{a.name}</span>)}</>;
};
```

You can apply query instructions inline:

```tsx
const members = use.members({
  with: {
    team: { notBeing: null },
    email: { endingWith: '@company.co' },
  },
  orderedBy: { descending: ['joinedAt'] },
});
```

## `useMutation` (Client)

Writes data and automatically revalidates all affected `use` queries. Exposes `add`, `set`, `remove`, and `batch`.

```tsx
import { useMutation } from 'blade/client/hooks';

export const EditAccount = () => {
  const { set, add, remove, batch } = useMutation();

  const handleSave = async () => {
    await set.account({
      with: { handle: 'elaine' },
      to: { handle: 'mia' },
    });
  };

  return <button onClick={handleSave}>Save</button>;
};
```

To redirect after a mutation:

```tsx
await add.account.with.handle('elaine', {
  redirect: '/accounts/{0.handle}',
});
```

## `usePagination` (Client)

Paginates a list by modifying the underlying `use` query. Pass the `nextPage` cursor from your read query:

```tsx
import { usePagination } from 'blade/client/hooks';

export const PostList = ({ records, nextPage }) => {
  const { paginate, resetPagination } = usePagination(nextPage);

  return (
    <div>
      <button onClick={paginate}>Load more</button>
      <button onClick={resetPagination}>Reset</button>
    </div>
  );
};
```

## `usePaginationBuffer` (Client)

Concatenates paginated pages into a single list, so you can render the full accumulated result:

```tsx
import { usePagination, usePaginationBuffer } from 'blade/client/hooks';

export const Feed = ({ children: defaultChildren, nextPage, previousPage }) => {
  const { paginate } = usePagination(nextPage);
  const [children] = usePaginationBuffer(defaultChildren, { previousPage });

  return (
    <div>
      {children}
      <button onClick={paginate}>Show more</button>
    </div>
  );
};
```

## `useLocation`

Returns a `URL` object for the current page. Dynamic segments are not populated (use `useParams` for those).

```tsx
import { useLocation } from 'blade/hooks';

const location = useLocation();
console.log(location.pathname);
```

## `useParams`

Returns the values of all dynamic path segments in the current URL.

```tsx
import { useParams } from 'blade/hooks';

const { handle } = useParams<{ handle: string }>();
```

## `useRedirect`

Navigates to a different page. Works on both server (throws a redirect) and client (performs a page transition).

```tsx
import { useRedirect } from 'blade/hooks';

const redirect = useRedirect();
redirect('/dashboard');
```

## `useCookie`

Reads and writes HTTP cookies. On the server, set cookies are attached to the response headers before the React stream begins. On the client, they update `document.cookie` directly.

```tsx
import { useCookie } from 'blade/hooks';

const [token, setToken] = useCookie('auth_token');

if (!token) setToken('new_value');
```

Cookies default to HTTP-only with a 365-day max age and a path of `/`. Pass `{ client: true }` to make a cookie accessible to JavaScript in the browser.

## `useQueryState` (Client)

Synchronizes a piece of React state with a URL query parameter. Reading the hook reads the parameter; setting it updates the URL.

```tsx
import { useQueryState } from 'blade/client/hooks';

export const SearchInput = () => {
  const [query, setQuery] = useQueryState('q');

  return (
    <input
      value={query ?? ''}
      onChange={e => setQuery(e.target.value)}
    />
  );
};
```

## `useLinkEvents` (Client)

Returns the `onClick`, `onMouseEnter`, and `onTouchStart` event handlers that Blade's `<Link>` component uses internally. Useful when you need to attach link behavior to a non-anchor element.

```tsx
import { useLinkEvents } from 'blade/client/hooks';

const events = useLinkEvents('/dashboard');
<div {...events}>Go to dashboard</div>
```
