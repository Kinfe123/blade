# Pages

Blade's page system works like a filesystem router. Files under `pages/` map directly to URL paths, and each file exports a default React component. Blade handles server-side rendering, streaming, and automatic revalidation for you.

## File conventions

- `pages/index.tsx` → `/`
- `pages/about.tsx` → `/about`
- `pages/posts/[id].tsx` → `/posts/:id`
- `pages/layout.tsx` → wraps all sibling pages and directories
- `pages/404.tsx` → rendered for unknown routes

Client components must end in `.client.tsx` (or `.client.ts`). Any file without `.client` in the name is treated as a server component and never shipped to the browser.

## Automatic revalidation (SWR)

Blade intelligently keeps data up-to-date. The output of every `use` query is automatically refreshed:

- When a mutation runs (in the same DB transaction as the mutation).
- Every 5 seconds, even if the window is not in focus.
- When the device was offline and comes back online.
- When the window regains focus.

Blade also revalidates the application itself. When you deploy a new version, Blade detects the version drift, unmounts the old React tree on the client, downloads the updated assets, and mounts the new app — without a full page reload.

## Layouts

A `layout.tsx` file wraps all pages in the same directory and in nested directories. Layouts can call `use` hooks just like pages, and their queries are batched together with the page's queries into a single database transaction.

```tsx
// pages/layout.tsx
import { use } from 'blade/server/hooks';

const Layout = ({ children }) => {
  const account = use.account.with.id('me');

  return (
    <div>
      <nav>Hello, {account.name}</nav>
      {children}
    </div>
  );
};

export default Layout;
```

## Dynamic routes

Wrap a segment in square brackets to make it dynamic. Access the value with `useParams`:

```tsx
import { use } from 'blade/server/hooks';
import { useParams } from 'blade/hooks';

const Page = () => {
  const { id } = useParams<{ id: string }>();
  const post = use.post.with.id(id);

  return <article>{post.title}</article>;
};

export default Page;
```

## MDX support

Blade builds MDX pages out of the box with zero configuration. Create a file with the `.mdx` extension and it renders as a React component:

```mdx
---
title: Hello World
---

# Hello World

You can use **Markdown** and <Button>React components</Button> together.
```

Frontmatter's `title` key is automatically used as the page title. A `TableOfContents` object derived from your headings is passed to the parent `layout.tsx` component, so you can build a sidebar navigation without any extra tooling.

## Page metadata

Call `useMetadata` from `blade/server/hooks` to set `<head>` tags for the current page:

```tsx
import { use, useMetadata } from 'blade/server/hooks';

const Page = () => {
  useMetadata({
    title: 'My page',
    description: 'A page built with Blade.',
  });

  return <main>Content</main>;
};

export default Page;
```
